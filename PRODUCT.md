# SkillDash

## Register

product

## Users

AI agents discover portable skills and tools through MCP, API, CLI and the agent guide. People inspect instructions and source details, choose an installation target, save skills and download complete folders. Creators submit free listings for owner review.

## Product Purpose

One public library replaces repeated searches across repositories. Help an agent or person find a relevant skill, inspect its pinned source and license, and use the complete folder. Source checksums and publication review are inspectable evidence, not a security certification.

## Brand Personality

Clear, practical, inspectable. Use the existing SkillDash identity: readable Geist typography, restrained green actions and calm surfaces. Show the workflow and useful details without exaggerated claims.

## Anti-references

The reported detail view with cropped dialog edges, disappearing close controls, an incomplete backdrop and dense unbounded prose is the concrete failure to avoid. Avoid decorative dashboard chrome, nested promotional cards and interface details that distract from inspection and installation.

## Design Principles

- Give agents a stable link and people a clear inspection workflow.
- Keep source, license and installation actions easy to find.
- Long instructions must remain readable without losing navigation.
- Adapt the structure to small screens and short windows.
- Preserve public browsing, free contribution and private account contacts.

## Accessibility & Inclusion

Retain native dialog focus containment and Escape dismissal, visible focus, semantic controls and reduced-motion behavior. Keep long code and tables inside their reading area. Maintain readable contrast and accessible touch targets. No additional audience-specific requirement is recorded.
